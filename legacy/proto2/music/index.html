Background loops without vocals

The new takes use a community add-on for YuE2 trained only on instrumental music (Mothersuperior, Hugging Face), with calmer tags ("background music, low energy, sparse, minimal"). Stable Audio 3 is a different local model made for instrumentals. Each file is a 45 to 60 s loop: the end fades into the start, and these players repeat, so you can hear the seam. The Demucs rows are checked with the same tool that removed the voice, so their number flatters them.
