# Approved art

One folder per bible id. Each file here is a copy of one that bible/facts.yaml marks approved (a `portrait:` or `image:` line, or an asset line with status approved), and the bible points here. If a file isn't in the bible, it isn't approved. The originals and every other candidate are in legacy/ (proto2/cast-fixed, proto2/locations1, proto2/locations2). Jørgen's own reference images are in art/refs/. Voice references stay in tools/voice-refs/.
